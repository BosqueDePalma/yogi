Install Yogi Timer

  1. Tap Share . If you don't see it, tap first.
  2. Tap Add to Home Screen . If you don't see it, tap More first.
  3. Keep Open as Web App on, then tap Add.
  4. Open Yogi Timer from your Home Screen once while you're online, so it works offline.
